# Kawaii Study Space

Bloom is a kawaii productivity dashboard for study sessions, tasks, notes, goals, habits, music, and short breaks.

## Project files

- `kawai website.html` is the standalone browser version with local login and sign-up.
- `New folder` contains the React + Vite version and its Express API.

## Run the React version

```powershell
cd "New folder"
npm install
npm run dev
```

Open `http://localhost:5173` in a browser.

The standalone version can be opened directly from `kawai website.html`.
